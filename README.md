## ✨ Fonctionnalités

- 🎨 **Design moderne** avec glassmorphism, animations fluides et effets de hover sophistiqués
- 🌙 **Mode sombre/clair** avec persistance du choix utilisateur
- 📱 **Responsive design** optimisé pour tous les appareils
- ⚡ **Performance optimisée** grâce à Next.js App Router
- **Formulaire de contact** fonctionnel avec protection reCAPTCHA v3
- 🎭 **Animations au scroll** fluides et modernes
- 🖼️ **Modales de projets** détaillées avec galeries d'images
